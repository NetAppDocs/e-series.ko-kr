= E-Series 스위치 구성 - Linux(RoCE를 통한 NVMe)
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NVMe over RoCE에 대한 공급업체의 권장 사항에 따라 스위치를 구성합니다. 이러한 권장 사항에는 구성 지시문과 코드 업데이트가 모두 포함될 수 있습니다.


CAUTION: *데이터 손실 위험.* NVMe/RoCE는 무손실 환경에서 실행해야 합니다. 데이터 손실 위험을 제거하려면 네트워크에서 글로벌 일시 정지 프레임 기반 흐름 제어(Global Pause Frame based Flow Control) 또는 우선순위 흐름 제어(Priority Flow Control, PFC)를 사용하여 종단 간 흐름 제어를 활성화하십시오.



[[global-pause-frames]]
== 전역 일시 중지 프레임

글로벌 일시 중지 프레임은 가장 기본적인 흐름 제어 형태이며 구현하기도 가장 간단합니다. 트래픽이 네트워크 포트를 압도하면 일시 중지 프레임이 생성되어 해당 포트의 모든 트래픽을 중단시키며, 이는 이전 트래픽이 충분히 처리되어 네트워크 포트가 수신 트래픽을 손실 없이 처리할 수 있을 때까지 지속됩니다.

.단계
. 스위치 공급업체에서 제공하는 설명서를 사용하여 글로벌 일시 정지 프레임 기반 흐름 제어를 *종단 간* 활성화하십시오.
. 이 환경에서 호스트, 어레이 및 스위치 간 링크에 연결된 모든 스위치 포트에서 글로벌 일시 정지 프레임 기반 흐름 제어가 활성화되어 있는지 확인하십시오.




[[priority-flow-control]]
== 우선순위 흐름 제어

Priority Flow Control(PFC)은 서로 다른 유형의 트래픽에 서로 다른 우선순위 레벨을 할당하는 보다 복잡한 형태의 흐름 제어입니다. 한 우선순위에서 너무 많은 트래픽이 수신되면 해당 트래픽은 일시 중지되고 다른 우선순위 레벨에 해당하는 트래픽은 계속 처리되어 특정 유형의 과도한 트래픽이 다른 형태의 트래픽을 지연시키는 것을 방지할 수 있습니다.

현재로서는 11.80.1을 실행하는 200Gb/s 이더넷 HIC(PN 111-04583)가 장착된 EF600 E-Series Array 또는 지원되는 NVMe/RoCE HIC가 장착된 EF80 E-Series Array를 사용해야 합니다. PFC 매개변수는 어레이에 하드 코딩되어 있으며 NVMe/RoCE 트래픽은 `106`의 DSCP 값으로 우선순위 3으로 태그되어야 합니다.

.단계
. PFC 값을 사용하여 네트워크를 설정하는 방법에 대한 자세한 내용은 스위치 공급업체 설명서를 참조하십시오.
. 사용자 환경에 가장 적합한 구성을 선택하는 방법은 네트워크 관리자에게 문의하십시오.
