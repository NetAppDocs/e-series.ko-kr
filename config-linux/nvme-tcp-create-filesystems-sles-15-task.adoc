= E-Series Linux NVMe over TCP 호스트용 파일 시스템 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
RHEL 9, RHEL 10, SLES 15 및 SLES 16의 경우 네이티브 nvme 장치에 파일 시스템을 생성하고 해당 파일 시스템을 마운트합니다.

.시작하기 전에
link:nvme-tcp-access-physical-targets-concept.html["호스트에서 E-Series 타겟의 NVMe 볼륨에 액세스"] 작업을 완료하여 NVMe 장치가 올바르게 구성되고 액세스할 수 있는지 확인하십시오.

.단계
. 위치를 사용하여 원하는 NVMe 장치의 파티션에 파일 시스템을 생성합니다 `/dev/disk/by-id/nvme-eui.[id#]`.
+
파일 시스템을 생성하는 방법은 선택한 파일 시스템에 따라 다릅니다. 이 예에서는 ext4 파일 시스템을 만드는 방법을 보여 줍니다.

+
[listing]
----
# mkfs.ext4 /dev/disk/by-id/nvme-eui.000082dd5c05d39300a0980000a52225
mke2fs 1.42.11 (22-Oct-2019)
Creating filesystem with 2620928 4k blocks and 655360 inodes
Filesystem UUID: 97f987e9-47b8-47f7-b434-bf3ebbe826d0
Superblock backups stored on blocks:
        32768, 98304, 163840, 229376, 294912, 819200, 884736, 1605632

Allocating group tables: done
Writing inode tables: done
Creating journal (32768 blocks): done
Writing superblocks and filesystem accounting information: done
----
. 새 디바이스를 마운트할 폴더를 생성합니다.
+
[listing]
----
# mkdir /mnt/ext4
----
. 디바이스를 마운트합니다.
+
[listing]
----
# mount /dev/disk/by-id/nvme-eui.000082dd5c05d39300a0980000a52225 /mnt/ext4
----


.다음 단계
파일 시스템을 생성한 후 link:nvme-tcp-worksheet-for-concept.html["NVMe over TCP 구성 정보를 기록해 두십시오."].
