= E-Series Linux NVMe over TCP 호스트에서 페일오버 설정
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 배열에 대한 중복 경로를 제공하기 위해 호스트에서 장애 조치를 실행하도록 구성할 수 있습니다.

.시작하기 전에
 https://mysupport.netapp.com/matrix["NetApp 상호 운용성 매트릭스 툴"^]를 참조하여 필요한 업데이트가 설치되어 있는지 확인하십시오. 초기 릴리스에서 사용할 수 없는 SLES 또는 RHEL 버전에 중요한 버그 수정이 필요할 수 있습니다.

.이 작업에 대해
SLES 15, SLES 16, RHEL 9 및 RHEL 10의 경우 네이티브 NVMe 멀티패싱이 기본적으로 활성화되어 있으므로 추가 구성이 필요하지 않습니다.



[[configure-nvme-io-policy]]
== NVMe I/O 정책 구성

.이 작업에 대해
Linux NVMe 네이티브 멀티패싱은 기본적으로  `numa` I/O 정책을 따릅니다. E-Series/EF-Series NVMe-over-Fabrics 구성의 경우 권장되는 I/O 정책은  `round-robin`이며, 모든 사용 가능한 경로에 I/O를 균등하게 분산합니다.

.단계
. 현재 NVMe I/O 정책을 확인하십시오.
+
[listing]
----
# cat /sys/module/nvme_core/parameters/iopolicy
numa
----
. 다음 방법 중 하나를 사용하여 `round-robin` I/O 정책을 설정하십시오.
+
** *지속적 유지(권장)* — udev 규칙 파일을 생성합니다.
+
.<code>/etc/udev/rules.d/71-nvme-io-policy.rules</code>
[listing]
----
ACTION=="add|change", SUBSYSTEM=="nvme-subsystem", ATTR{iopolicy}="round-robin"
----
+
그런 다음 규칙을 다시 로드하고 적용합니다.

+
[listing]
----
udevadm control --reload
udevadm trigger --subsystem-match=nvme-subsystem
----
** *부팅 시 전역 설정* — 부트로더 구성에 다음 커널 매개 변수를 추가합니다.
+
[listing]
----
nvme_core.iopolicy=round-robin
----
** *비영구적(온라인, I/O 중단 없음)* — 재부팅 없이 즉시 적용:
+
[listing]
----
echo "round-robin" > /sys/class/nvme-subsystem/nvme-subsys0/iopolicy
----
+

NOTE: 이 설정은 재부팅 후에는 유지되지 않습니다.
