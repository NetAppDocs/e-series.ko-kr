= E-Series VMware 호스트에서 다중 경로가 작동하는 방식
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스토리지 어레이에 대한 이중화 경로를 제공하려면 다중 경로 소프트웨어를 구성하십시오.

물리적 경로 중 하나가 중단되는 경우 다중 경로 소프트웨어가 스토리지 배열에 대한 중복 경로를 제공합니다. 다중 경로 소프트웨어는 스토리지에 대한 활성 물리적 경로를 나타내는 단일 가상 장치를 운영 체제에 제공합니다. 또한 다중 경로 소프트웨어는 가상 장치를 업데이트하는 페일오버 프로세스를 관리합니다.



[[multipathing-policies]]
== 다중 경로 정책

다중 경로 정책에 대한 자세한 내용은 아래와 같습니다. FCP, iSCSI 및 SAS 프로토콜의 경우 기본값은 NMP(Native Multipathing Plug-Ins)입니다. NVMe over Fabrics(NVMe over FC, NVMe over RoCE 및 NVMe over TCP)의 경우 기본값은 HPP(High Performance Plug-In)입니다.



[[native-multipathing-plug-ins-nmp]]
=== 네이티브 다중 경로 플러그인(NMP)

FCP, iSCSI 및 SAS 프로토콜에만 적용 가능하며,  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/understanding-multipathing-and-failover-in-the-esxi-environment/vmware-multipathing-module.html["VMware는 네이티브 다중 경로 플러그인(NMP)을 제공합니다."^], SATP(Storage Array Type Plug-ins)라고 하며, 특정 공급업체의 스토리지 어레이의 장애 조치 구현을 처리합니다.

사용해야 할 SATP는 *VMW_SATP_ALUA*입니다(이는 NetApp E-Series의 기본값입니다). 자세한 내용은 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/understanding-multipathing-and-failover-in-the-esxi-environment/vmware-satps.html["VMware SATP"^]을 참조하십시오.



==== 경로 선택 플러그인 및 정책(PSP)

이 플러그인은 VMware NMP의 하위 모듈입니다. NMP는 장치 유형에 따라 각 논리 장치에 기본 PSP를 할당합니다. 기본 PSP를 재정의할 수 있습니다. 자세한 내용은 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/understanding-multipathing-and-failover-in-the-esxi-environment/viewing-and-managing-storage-paths-on-esxi-hosts/change-the-path-selection-policy.html["경로 선택 정책 변경"^]을 참조하십시오. NMP는 NetApp 장치에 대해 기본 경로 선택 정책으로 VMW_PSP_RR(라운드 로빈)을 할당합니다. 이는 권장되는 PSP입니다.

자세한 내용은 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/understanding-multipathing-and-failover-in-the-esxi-environment/vmware-psps.html["VMware 경로 선택 플러그인 및 정책"^]을 참조하십시오.



[[high-performance-plug-in-hpp]]
=== 고성능 플러그인(HPP)

HPP는 NVMe 등 고속 장치에서 NMP를 대체합니다. HPP는 NVMe-oF 타겟을 지정하는 기본 플러그인입니다. ESX는 에뮬레이션 없이 엔드투엔드 NVMe를 지원하며 SCSI-NVMe 에뮬레이션도 지원합니다. HPP는 액티브/액티브 및 암시적 ALUA 타겟만 지원합니다.



==== 경로 선택 방식(PSS)

다중 경로를 지원하기 위해 HPP는 I/O 요청에 대한 물리적 경로를 선택할 때 경로 선택 체계(PSS)를 사용합니다. HPP가 할당한 장치에 대한 기본 체계는 LB-RR(로드 밸런싱 - 라운드 로빈)입니다. 이는 권장되는 PSS입니다.

HPP 또는 PSS에 대한 자세한 내용은  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/understanding-multipathing-and-failover-in-the-esxi-environment/vmware-hpp.html["VMware High Performance Plug-In 및 경로 선택 체계"^]을 참조하십시오.
